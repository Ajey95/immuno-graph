# Contributing

ImmunoGraph accepts focused bug fixes, reproducibility improvements, tests, and documentation updates. Open an issue before changing a public MCP tool contract or adding a scientific method.

1. Fork the repository and work on a focused branch.
2. Run `npm ci`, `npm test`, `npm run build`, and `npm audit --audit-level=high`.
3. Describe the tool behavior, scientific provenance, and verification in the pull request.

Do not add credentials, patient data, proprietary datasets, generated research results, or unlicensed assets. Keep synthetic and fixture evidence visibly labeled. New scientific methods need a versioned contract, explicit source provenance, and deterministic tests where applicable.
